# Office Stretching App 🧘‍♂️💻

> แอปพลิเคชันช่วยเตือนและพายืดเหยียดลดออฟฟิศซินโดรมแบบตรวจจับท่าทางด้วย AI สำหรับชาวออฟฟิศ

แอปพลิเคชันเว็บแบบ **Single-file HTML (ไฟล์เดียวจบ)** ที่ออกแบบมาเพื่อพนักงานออฟฟิศที่นั่งทำงานหน้าจอโน้ตบุ๊ก/คอมพิวเตอร์ โดยมีระบบ AI ตรวจจับข้อต่อร่างกายช่วงบนด้วย **ml5.js BodyPose (MoveNet)** และ **p5.js** ประมวลผลภาพภายในเครื่อง 100% ปลอดภัย ไม่มีการส่งข้อมูลภาพออกภายนอก

---

## 🌟 ฟีเจอร์เด่น
1. **ระบบจับเวลาทำงานอัจฉริยะ**: เลือกได้ 3 นาที (โหมดทดสอบ), 25 นาที (Pomodoro), หรือ 50 นาที (มาตรฐาน)
2. **ระบบแจ้งเตือน**: มีเสียงเตือน พร้อมรองรับการแจ้งเตือนบนหน้าจอคอมพิวเตอร์ (Desktop Notification) แม้เปิดโปรแกรมอื่นอยู่
3. **5 ท่ายืดเหยียดสำหรับคนนั่งหน้าคอมพ์ (Desk & Sitting Friendly)**:
   - 🙏 **ท่าที่ 1: พนมมือกลางอก** (ยืดคลายข้อมือจากการใช้เมาส์/คีย์บอร์ด)
   - 🙇‍♂️ **ท่าที่ 2: มือแตะหัวไหล่สองข้าง** (คลายกล้ามเนื้อบ่าและสะบัก)
   - 🙆‍♂️ **ท่าที่ 3: สองมือแตะท้ายทอย** (เปิดแผงอก แก้หลังค่อมและไหล่ห่อ)
   - 👤 **ท่าที่ 4: เอียงคอไปทางซ้าย** (ยืดกล้ามเนื้อคอ-บ่าด้านขวา)
   - 👤 **ท่าที่ 5: เอียงคอไปทางขวา** (ยืดกล้ามเนื้อคอ-บ่าด้านซ้าย)
4. **ระบบตรวจจับท่าทางและนับเวลาค้าง (Hold Timer)**: ค้างท่าละ 4 วินาที พร้อมแถบสถานะและเส้นโครงกระดูกเรืองแสงสีเขียวเมื่อทำท่าถูกต้อง
5. **เสียงแนะนำภาษาไทย (Web Speech API)**: ส่งเสียงบอกชื่อท่าและชมเชยเมื่อทำผ่าน
6. **ระบบสรุปสถิติ & วนลูปอัตโนมัติ**: บันทึกสถิติจำนวนรอบสำเร็จของวันลงในเครื่อง (LocalStorage) และนับถอยหลังเริ่มรอบใหม่โดยอัตโนมัติ

## 🚀 วิธีเปิดใช้งาน
เพียงเปิดไฟล์ `index.html` บนเว็บเบราว์เซอร์ (Google Chrome, Microsoft Edge, Safari) แล้วกด **อนุญาต (Allow)** การใช้งานกล้องเว็บแคม
